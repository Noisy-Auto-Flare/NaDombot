## 📝 Описание

Бот предназначен для хранения и просмотра домашнего задания по школьному расписанию. Поддерживает две роли:
- **Администратор** - может управлять расписанием
- **Обычные пользователи** - могут добавлять и просматривать домашнее задание

## 🏗 Архитектура проекта

Проект построен на следующих технологиях:

- **Node.js** - серверная платформа
- **Telegraf** - библиотека для работы с Telegram Bot API
- **PostgreSQL** - реляционная база данных
- **Sequelize** - ORM для работы с БД
- **Docker & Docker Compose** - контейнеризация и оркестрация

### Основные компоненты:

1. **Бот (Telegraf)** - обрабатывает команды и сообщения от пользователей
2. **Сцены (Scenes)** - реализуют пошаговые диалоги для добавления ДЗ и управления расписанием
3. **Модели (Sequelize)** - определяют структуру данных в БД
4. **Утилиты** - вспомогательные функции для работы с датами и расписанием

## 🗄 Схема базы данных

### Таблица `schedules` (Расписание)

Хранит информацию о расписании уроков на неделю.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INTEGER | Первичный ключ (автоинкремент) |
| `lessonNumber` | INTEGER | Номер урока (1-7) |
| `subjectName` | VARCHAR(100) | Название предмета |
| `dayOfWeek` | INTEGER | День недели (0=Понедельник, 6=Воскресенье) |
| `createdAt` | TIMESTAMP | Дата создания |
| `updatedAt` | TIMESTAMP | Дата обновления |

**Индексы:**
- Уникальный индекс на `(dayOfWeek, lessonNumber)` - предотвращает дублирование уроков в один день

### Таблица `homeworks` (Домашнее задание)

Хранит информацию о домашних заданиях пользователей.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INTEGER | Первичный ключ (автоинкремент) |
| `userId` | BIGINT | Telegram ID пользователя |
| `scheduleId` | INTEGER | ID урока из расписания (FK) |
| `date` | DATE | Дата урока, к которому относится ДЗ |
| `content` | TEXT | Текст домашнего задания |
| `createdAt` | TIMESTAMP | Дата создания |
| `updatedAt` | TIMESTAMP | Дата обновления |

**Индексы:**
- Составной индекс на `(userId, date, scheduleId)` - для быстрого поиска ДЗ пользователя
- Индекс на `date` - для фильтрации по дате

**Связи:**
- `homeworks.scheduleId` → `schedules.id` (многие к одному)

## ⚙️ Функциональность

### Для всех пользователей:

1. **Добавление домашнего задания**
   - Пользователь вводит название предмета
   - Бот автоматически находит ближайший будущий урок по этому предмету
   - Пользователь вводит текст домашнего задания
   - ДЗ сохраняется в БД

2. **Просмотр домашнего задания на завтра**
   - Выводит список уроков и домашнее задание на следующий день

3. **Просмотр домашнего задания на неделю**
   - Выводит домашнее задание на каждый день недели
   - Структурировано по дням

### Для администратора:

1. **Управление расписанием**
   - Добавление уроков в расписание
   - Просмотр всего расписания
   - Удаление уроков из расписания

## 🚀 Установка и запуск

### Предварительные требования

- Docker и Docker Compose установлены на вашей системе
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))
- Telegram ID администратора (можно узнать у [@userinfobot](https://t.me/userinfobot))

### Шаг 1: Клонирование и настройка

```bash
# Перейдите в директорию проекта
cd tgdomashkabot

# Создайте файл .env на основе примера
cp .env.example .env

# Откройте .env и заполните необходимые переменные
nano .env  # или используйте любой текстовый редактор
```

### Шаг 2: Настройка переменных окружения

Отредактируйте файл `.env`:

```env
# Telegram Bot Token (получить у @BotFather)
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# ID администратора (можно узнать у @userinfobot)
ADMIN_ID=123456789

# База данных (можно оставить значения по умолчанию)
DB_NAME=homework_db
DB_USER=postgres
DB_PASSWORD=postgres
DB_PORT=5432

# Node environment
NODE_ENV=production
```

### Шаг 3: Запуск через Docker Compose

```bash
# Сборка и запуск контейнеров
docker-compose up -d

# Просмотр логов бота
docker-compose logs -f bot

# Просмотр логов базы данных
docker-compose logs -f postgres
```

### Шаг 4: Проверка работы

1. Найдите вашего бота в Telegram по имени, которое вы указали при создании у @BotFather
2. Отправьте команду `/start`
3. Должно появиться главное меню с кнопками

### Остановка

```bash
# Остановка контейнеров
docker-compose down

# Остановка с удалением данных БД (осторожно!)
docker-compose down -v
```

## 📖 Использование

### Для обычных пользователей:

1. **Добавление домашнего задания:**
   - Нажмите кнопку "➕ Добавить домашнее задание"
   - Введите название предмета (например: "Математика")
   - Бот найдет ближайший урок и попросит ввести текст ДЗ
   - Введите текст домашнего задания

2. **Просмотр ДЗ на завтра:**
   - Нажмите кнопку "📅 Домашнее задание на завтра"
   - Увидите список уроков и домашнее задание на следующий день

3. **Просмотр ДЗ на неделю:**
   - Нажмите кнопку "📆 Домашнее задание на неделю"
   - Увидите домашнее задание на всю неделю, структурированное по дням

### Для администратора:

1. **Добавление урока в расписание:**
   - Нажмите кнопку "⚙️ Управление расписанием"
   - Выберите "➕ Добавить урок"
   - Введите данные в формате: `<день_недели> <номер_урока> <название_предмета>`
   - Пример: `0 1 Математика` (Понедельник, 1 урок, Математика)

2. **Просмотр расписания:**
   - В меню управления расписанием выберите "📋 Просмотреть расписание"

3. **Удаление урока:**
   - В меню управления расписанием выберите "🗑 Удалить урок"
   - Введите ID урока (можно узнать из просмотра расписания)

### Формат дней недели:

- `0` - Понедельник
- `1` - Вторник
- `2` - Среда
- `3` - Четверг
- `4` - Пятница
- `5` - Суббота
- `6` - Воскресенье

## 🔧 Разработка

### Локальная разработка без Docker

```bash
# Установка зависимостей
npm install

# Создайте файл .env (см. выше)

# Убедитесь, что PostgreSQL запущен локально

# Запуск в режиме разработки
npm run dev
```

### Структура основных файлов

#### `src/index.js` - Точка входа

Инициализирует бота, регистрирует сцены и обработчики команд.

#### `src/scenes/addHomeworkScene.js` - Сцена добавления ДЗ

Реализует пошаговый диалог:
1. Запрос названия предмета
2. Поиск ближайшего урока
3. Запрос текста ДЗ
4. Сохранение в БД

#### `src/utils/scheduleUtils.js` - Утилиты расписания

Содержит функции:
- `findNextLesson()` - поиск ближайшего урока по предмету
- `getHomeworkForDate()` - получение ДЗ на конкретную дату
- `getHomeworkForWeek()` - получение ДЗ на неделю
- `formatHomework()` - форматирование ДЗ для отображения

## 🐛 Решение проблем

### Бот не отвечает

1. Проверьте, что контейнер запущен: `docker-compose ps`
2. Проверьте логи: `docker-compose logs bot`
3. Убедитесь, что `BOT_TOKEN` правильный в `.env`

### Ошибки подключения к БД

1. Проверьте, что контейнер PostgreSQL запущен: `docker-compose ps`
2. Проверьте логи БД: `docker-compose logs postgres`
3. Убедитесь, что переменные БД в `.env` совпадают с `docker-compose.yml`

### Данные не сохраняются

1. Проверьте, что том `postgres_data` создан: `docker volume ls`
2. Убедитесь, что не используете `docker-compose down -v` (это удаляет данные)
